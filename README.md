# 🎯 Number Guessing Game

## 📌 Project Overview

The **Number Guessing Game** is a simple and interactive Python-based game developed using **Tkinter**. The computer randomly generates a number, and the player has to guess the number within the given range.

The game provides hints such as **"Too High"** or **"Too Low"** to help the player find the correct number.

## ✨ Features

* 🎲 Random number generation
* 🖥️ Interactive Tkinter GUI
* 🔢 User-friendly number input
* 💡 Hints for every guess
* 🏆 Displays the number of attempts
* 🔄 New Game / Reset option
* ❌ Input validation for invalid values
* 🎨 Simple and attractive interface

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Random Module**

## 🎮 How to Play

1. Start the game.
2. The computer generates a random number.
3. Enter your guessed number in the input box.
4. Click **Guess**.
5. Follow the hint:

   * 🔼 **Too High** – Guess a smaller number.
   * 🔽 **Too Low** – Guess a larger number.
   * 🎉 **Correct** – You guessed the number!
6. Try to find the number using the minimum number of attempts.
